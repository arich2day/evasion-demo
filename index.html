Test 7: Web Socket + Malware

Network layer security can't inspect WebSocket connections because they're encrypted. Therefore, these solutions are completely blind to threats transmitted through these persistent connections.

The browser sends an HTTP request to the server, and the server responds with a Status Code 101 (Switching Protocols), upgrading the connection from standard HTTP to the bidirectional WebSocket protocol (ws:// or wss://).

Test 8: Malicious Obfuscation (Obfuscated JavaScript)

The script uses a large number of variables, each holding a small fragment of a string encoded with hexadecimal (\x50\x47...) or Unicode (\u0046\u007a...) escape sequences. This makes the text unreadable to a human or a network security scanner.
